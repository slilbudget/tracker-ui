# План работ

Сервер под готовую админку. Контракт — объект `api` в [`src/api/client.ts`](../src/api/client.ts) и `client-*.ts`, поля — [`src/api/types.ts`](../src/api/types.ts), правила — [backend.md](backend.md) и [domain.md](domain.md), данные — [data-architecture.md](data-architecture.md).

**Готово** у любой задачи: сквозной сценарий её страниц (Playwright) проходит на настоящем API; права проверяются на сервере; запросы описаны в OpenAPI; есть тесты.

BE — Go, DE — дата-инженер, FE — фронтенд.

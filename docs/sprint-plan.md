# План работ по спринтам

От прототипа к работающему трекеру. Спринт — 2 недели. Команда для расчёта: 2–3 Go-разработчика (BE), дата-инженер (DE), фронтенд (FE), тимлид или продакт на приёмку. Оценки грубые, в днях одного человека; их надо пересмотреть с командой на первом планировании.

Интерфейс уже сделан и работает на тестовых данных. Каждая задача бэкенда закрывается одинаково: страница админки переключается с тестовых данных на настоящий API и работает так же. Что должен делать каждый запрос — в [`src/api/client.ts`](../src/api/client.ts), правила — в [backend.md](backend.md) и [domain.md](domain.md), данные — в [data-architecture.md](data-architecture.md).

**Готово** у любой задачи = код в main, тесты, запрос описан в OpenAPI, страница админки работает на настоящих данных, права доступа проверены на сервере.

## Риски

- **Объём кликов неизвестен.** Если он большой, на спринт 4 нужны агрегаты и больше времени.
- **Сборщик расходов FB** — внешний компонент. Если его формат поменяется, спринт 5 сдвинется.
- **Постбеки партнёрок** у всех разные. На каждую партнёрку нужен шаблон и тест.
- Интерфейс почти готов, поэтому основной объём работы — серверная часть. Без договора API (0.1) фронт и бэкенд разойдутся.
